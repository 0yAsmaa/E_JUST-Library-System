# E-JUST Library System

**Course:** CNC 111 - Web Programming

## Team Members
- Hana

## Project Description
A web-based system to manage the E-JUST library's day-to-day activities, including book borrowing, study room booking, and library registration.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Responsive Design)

## Pages Implemented (10 Pages)
1. Login / Register
2. Home Page (Student & Librarian)
3. Library Registration
4. Books
5. Borrowing
6. Librarian - Library Registration Analysis
7. Librarian - Books Analysis
